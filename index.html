Save your recovery file

Save a copy while your rollup app is available. The file contains the recipient, amount, Merkle proof, and signed settlement receipt. Keep it somewhere you can reach from another device.

Check the withdrawal status

Open the file in Exit Kit. It checks the proof and settlement receipt against Diana before showing the amount and recipient.

Ready to claim
The batch is final. Review the destination and continue with QoreX.
Waiting for finality
Wait for the batch to finalize, then check the withdrawal again.
Already claimed
Diana recorded the payout. You can open its transaction in the explorer.

Claim on Diana

Review the withdrawal in QoreX and approve the claim and network fee. The recipient address is fixed by the proof. A separate account can submit the claim and pay the fee.

If QoreX cannot display the withdrawal, the independent command-line signer can verify the same file and submit a hybrid-signed transaction with your approval.

Troubleshoot a claim

If Diana is temporarily unavailable, check again. If the batch or proof is missing, contact the rollup operator or verify the available state through your own QoreChain node.

For a lost file, find a paid withdrawal by its L1 hash. For an unpaid withdrawal, create a file with the proof supplied by your rollup.

Recovery file privacy

Exit Kit reads the file on your device and uses public rollup and batch identifiers to query Diana. When you approve a claim, your wallet sends the withdrawal transaction and proof to QoreChain.
