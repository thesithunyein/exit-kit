Recovery guide.

What you need to complete a withdrawal on QoreChain Diana.

Save your file while the rollup is available

A recovery file contains the recipient, amount, Merkle proof, and signed settlement receipt. Keep a copy somewhere you can reach from another device.

Open the file and check the claim

Exit Kit verifies the file against Diana. A withdrawal is ready once its batch is final and QoreChain still has the state needed to execute it.

Send the claim to QoreChain

Use the signing route shown after verification. The payout address is fixed by the proof. A separate account may submit the claim and pay the network fee.

If QoreX cannot display the withdrawal, use the independent command-line signer linked below. It verifies the same file and sends a hybrid-signed transaction only when you explicitly approve it.

Open command-line instructions

When the chain can’t verify a claim

Try again if the network is temporarily unavailable. If the batch or proof is missing, check with the rollup operator or use your own QoreChain node to verify available state.
